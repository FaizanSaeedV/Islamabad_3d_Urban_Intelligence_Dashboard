# Tests

- `backend/` — pytest unit and API tests (FastAPI TestClient); run with `pytest tests/backend` from the repository root (backend venv active).
- `spatial/` — spatial-result validation: CRS correctness, distance sanity checks against known Islamabad reference points, geometry validity of API output.
- `MANUAL_TESTING_CHECKLIST.md` — frontend manual test procedure (added in Milestone 11).
