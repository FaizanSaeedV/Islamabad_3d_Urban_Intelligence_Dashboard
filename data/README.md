# Data

Script-generated datasets (gitignored — reproduce with `scripts/`):

- `raw/` — unmodified Overpass API downloads (GeoJSON), one file per theme.
- `processed/` — validated, cleaned, analysis-ready GeoJSON.
- `tiles/` — generated 3D/CZML assets where applicable.

All data derives from OpenStreetMap (© OpenStreetMap contributors, ODbL 1.0) unless a file header states otherwise. No official government datasets are included or fabricated. Simulation tables are generated data clearly labelled "Simulated for Digital Twin Demonstration".
